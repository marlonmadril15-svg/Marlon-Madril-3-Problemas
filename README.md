# Tres ejercicios sencillos en Java con MVC

Este repositorio contiene tres proyectos independientes de Eclipse. Cada proyecto organiza las clases en los paquetes `control`, `modelo` y `vista`. La clase `Main.java` se encuentra en `control`.

## Proyectos

1. `Ejercicio1_PlantasMVC`: registro sencillo de plantas de huerto.
2. `Ejercicio2_GastosMVC`: registro de gastos diarios.
3. `Ejercicio3_ReservasCanchaMVC`: registro de reservas de una cancha deportiva.

Cada proyecto incluye `.project`, `.classpath`, el código fuente en `src` y archivos de texto en `datos`.

## Importar en Eclipse

1. Descarga el repositorio con **Code > Download ZIP** y descomprímelo.
2. En Eclipse selecciona **File > Import > General > Existing Projects into Workspace**.
3. Selecciona la carpeta descomprimida y marca los tres proyectos.
4. Pulsa **Finish**.
5. Ejecuta `src/control/Main.java` del proyecto que quieras usar con **Run As > Java Application**.
